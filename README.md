# FinBot Git Training

Учебный репозиторий команды FinBot.

## Цель

Научиться правильно работать с Git и GitHub в команде.

## Правила

- Не изменяем `main` напрямую.
- Каждая задача выполняется в отдельной ветке.
- Изменения принимаются через Pull Request.
- Перед объединением проводится проверка.
